How it will work

Everything in the Razor/KRoC toolchain needed to run occam is portable C, so the whole pipeline can be compiled to WebAssembly and run in the browser with no server:

  1. Compiler. Build occ21 from Razor with Emscripten. It reads source and writes transputer-style intermediate code.
  2. Linker. Port the Transterpreter's bytecode linker to JavaScript or WebAssembly.
  3. Runtime. The Transterpreter VM is already a small, portable C interpreter, which makes it well suited to WebAssembly. Connect its screen and keyboard channels to the page.
  4. Visualise. Because process networks are explicit in occam, the playground can draw the running network as a live process diagram, with channels lighting up as they communicate.

Other routes: SPoC generates C, which could be compiled to WebAssembly on a server, and the JavaScript transputer emulator can already run the original Inmos toolchain in a browser.
