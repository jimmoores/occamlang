Lesson 3 of 4

Legoland

Peter Welch's classic: a box of tiny processes that snap together into networks that count, sum and generate Fibonacci numbers, with no loops over state.

The bricks

Each brick is a few lines, runs forever, and does one thing to a stream of integers. PLUS is used instead of + so the streams wrap around instead of failing on overflow.

Look at plus and delta. Each uses a small PAR inside its loop, so it does not care which input arrives, or which reader is ready, first. That is what makes the bricks safe to connect in any shape.

numbers

Feed succ's output back into its own input, seed the loop with prefix (0, ...), and tap the stream with delta:

PROC numbers (CHAN INT out!)
  CHAN INT a, b, c:
  PAR
    prefix (0, c?, a!)
    delta (a?, out!, b!)
    succ (b?, c!)
:

Every arrow in the diagram is a channel in the CHAN declaration, and every box is one line of the PAR. The program keeps no counter: the count exists only as the value moving around the loop.

integrate

Replace succ with plus and bring in an external stream. The loop now holds a running total:

PROC integrate (CHAN INT in?, out!)
  CHAN INT a, b, c:
  PAR
    plus (in?, c?, a!)
    delta (a?, out!, b!)
    prefix (0, b?, c!)
:

pairs

Add each value to the one after it. Split the stream, drop the first value from one copy with tail, and add the two streams back together:

PROC pairs (CHAN INT in?, out!)
  CHAN INT a, b, c:
  PAR
    delta (in?, a!, b!)
    tail (b?, c!)
    plus (a?, c?, out!)
:

Run it

Connect numbers to integrate and print the result. You get the triangular numbers 0, 1, 3, 6, 10, 15, … Every process here runs forever, so stop the program with Ctrl-C.

Exercise: Fibonacci Build a network that outputs 0, 1, 1, 2, 3, 5, 8, … using only prefix, delta and pairs. Hint: two prefixes in a loop. Sketch the diagram first.
solution 
PROC fibonacci (CHAN INT out!)
  CHAN INT a, b, c, d:
  PAR
    prefix (1, d?, a!)
    prefix (0, a?, b!)
    delta (b?, out!, c!)
    pairs (c?, d!)
:

Stream b is 0, 1, 1, 2, 3, …; pairs turns it into 1, 2, 3, 5, …; the two prefixes put 0 and 1 in front, which closes the loop.
