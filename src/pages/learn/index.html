Learn occam by example

Four short lessons, each built around programs that compile and run under Razor or KRoC. Every network is drawn as a process diagram, and every listing can be folded and viewed as lecture notes.

lesson 1

Your first program

Hello world, indentation as syntax, declarations, SEQ, IF, WHILE and replicators.

 lesson 2

Processes & channels

PAR, synchronous communication, the rules that rule out data races, and your first deadlock.

 lesson 3

Legoland

Peter Welch's small reusable processes, composed into numbers, integrate, pairs and Fibonacci.

 lesson 4

Choice & time

ALT, guards, PRI ALT, replicated alternation and TIMER timeouts.

Setting up

The lessons use occam-π as accepted by Razor (and KRoC), along with KRoC's standard course module for text output. Install Razor, then:

source /usr/local/razor/bin/razor-setup.sh
occbuild --program hello.occ
./hello

Most examples are also valid occam 2.1 apart from the channel direction markers (in?, out!). Remove those and write CHAN OF INT to use an older compiler such as SPoC.

We plan to let you run the examples in your browser.
