The style of the website should incorporate the inmos style occam branding, 
which was a specific Helventica style sans-serif font, which can be found on 
surviving Inmos technical notes, documentation, etc.  One interesting aspect
of occam was the common use of folding editors in development environments,
perhaps this theme could be incorporated somehow?  Peter welch pioneered the
use of process diagrams with vertices representing channels and boxes for 
processes.  This was a common way of architecting occam/CSP software and 
could be nested in the same way as folding.  Another common style when 
teaching was the use of handwritten lowercase occam keywords where the 
keyword was instead underlined.
